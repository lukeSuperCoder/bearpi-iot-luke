# BearPi-IoT_Std 开发板技术指南

本文档基于开发板官方文档及电路原理图分析整理，涵盖硬件规格、各模块电路原理、引脚映射及开发注意事项。

---

## 一、开发板概述

BearPi-IoT_Std 是由南京小熊派智能科技有限公司联合华为技术有限公司设计的物联网开发板，主控为 **STM32L431RCT6**（Cortex-M4F @ 80MHz），面向物联网感知层设备的快速原型开发。

### 核心参数

| 参数 | 规格 |
|------|------|
| MCU | STM32L431RCT6, Cortex-M4F, 80MHz |
| Flash | 256KB（内部）+ 8MB QSPI 外扩（W25Q64） |
| SRAM | 64KB |
| 供电 | USB 5V 或外部 5V，内部 DCDC 降至 3.3V |
| 显示 | 1.3" TFT LCD, 240×240, 4线 SPI |
| 通信扩展 | NB-IoT / 2G / WiFi / LoRa |
| 调试 | 板载 ST-Link（STM32F103C8T6）, SWD + 虚拟串口 |
| 晶振 | 8MHz（主时钟）+ 32.768KHz（RTC） |
| SD 卡 | 最大 32GB，SDMMC 接口 |

## 二、系统框图与总线架构

系统以 STM32L431RCT6 为核心，各模块通过以下总线连接：

```
                        ┌─────────────────┐
    USB 5V ──► DCDC 3.3V ──►│  STM32L431RCT6  │
                            │   (主控 MCU)    │
    ┌──────────┐            │                 │            ┌──────────┐
    │STM32F103 │◄── SWD ───►│                 │◄─ SPI ────►│ 8MB Flash│
    │(ST-Link) │◄── UART ──►│                 │  (QSPI)    │ (W25Q64) │
    └──────────┘            │                 │            └──────────┘
       │                    │                 │
     USB                    │                 │◄─ SDMMC ──► SD 卡
    (PC端)                  │                 │
                           │                 │◄─ SPI ────► LCD (240×240)
                           │                 │
                           │    ┌─────────┐  │
                           │    │E53 扩展 │◄─┤─ SPI/I2C/UART/ADC
                           │    └─────────┘  │
                           │    ┌─────────┐  │
                           │    │通信扩展 │◄─┤─ UART/SPI3
                           │    └─────────┘  │
                           │                 │
                           │    LED ← GPIO   │
                           │    按键 ← GPIO   │
                           └─────────────────┘
```

| 总线 | 连接模块 | 说明 |
|------|---------|------|
| SWD | ST-Link ↔ 主控 | 程序下载、在线调试 |
| UART1 | ST-Link ↔ 主控 | 调试 printf 输出（虚拟 COM 口） |
| SPI1 | E53 扩展接口 | 传感器 SPI 通信 |
| SPI2 | LCD 显示屏 | 4线 SPI, 240×240 TFT |
| SPI3 | 通信扩展接口 | 通信模组 SPI 通信 |

| SDMMC | SD 卡 | 三线 SD 协议 |
| I2C1 | E53 扩展接口 | 传感器 I2C 通信 |
| I2C3 | 预留接口 | 用户自定义 |
| UART2 | 预留接口 | 用户自定义 |
| UART3 | E53 扩展接口 | 传感器串口通信 |
| ADC1 | E53 扩展接口 | 模拟信号采集 |
| GPIO | LED / 按键 / 各扩展 | 状态指示与用户输入 |

## 三、电路原理图详解

### 3.1 ST-Link 调试电路

板载 ST-Link 使用 **STM32F103C8T6**（LQFP48）作为调试芯片，实现 USB 转 SWD + UART 功能。

#### 引脚分配

| 功能 | 引脚 | 说明 |
|------|------|------|
| SWCLK | PA14 | SWD 时钟，连接主控 SWD 接口 |
| SWDIO | PA13 | SWD 数据，连接主控 SWD 接口 |
| USART1_TX | PA9 | 虚拟串口发送（PC ← 开发板） |
| USART1_RX | PA10 | 虚拟串口接收（PC → 开发板） |
| USB D+ | PA12 | USB 数据正 |
| USB D- | PA11 | USB 数据负 |
| BOOT0 | 引脚44 | R22(10K) 下拉，从 Flash 启动 |
| NRST | 引脚8 | R23(10K) 上拉至 VCC_3.3 |

#### 关键外围器件

| 器件 | 值 | 作用 |
|------|------|------|
| Y1 | 8MHz 晶振 | 系统主时钟 |
| C27, C28 | 22pF | 晶振负载电容 |
| C23-C26 | 100nF | 电源去耦电容 |
| C29 | 10nF | 复位滤波 |
| R22 | 10K | BOOT0 下拉 |
| R23 | 10K | NRST 上拉 |
| R24 | 10K | USB RENUM 上拉 |

#### 调试接口（Header 4）

| 引脚 | 信号 | 功能 |
|------|------|------|
| 1 | VCC_3.3 | 电源 |
| 2 | GND | 地 |
| 3 | T_JTCK (SWCLK) | SWD 时钟 |
| 4 | T_JTMS (SWDIO) | SWD 数据 |
| - | T_SILK RX | UART 接收 |
| - | T_SILK TX | UART 发送 |

### 3.2 按键电路

开发板包含 3 个按键：1 个复位键（S2）+ 2 个功能键（S3/KEY2、S4/KEY1）。

#### 电路特性

所有按键均采用 **上拉电阻 + 接地按键** 架构，**低电平有效**：

| 按键 | 编号 | 连接引脚 | 上拉电阻 | 去抖电容 | 说明 |
|------|------|---------|---------|---------|------|
| RESET KEY | S2 | NRST | R8(10K) + R9(10K) | C14(10nF) | 硬件复位，直连 MCU Reset Pin |
| KEY2 | S3 | PB3 | R10(10K) | C15(10nF) | 用户功能键 |
| KEY1 | S4 | PB2 | R11(10K) | C16(10nF) | 用户功能键 |

#### 工作原理

- 未按下：GPIO 通过 10K 上拉电阻保持 **高电平**（3.3V）
- 按下时：GPIO 通过按键接地变为 **低电平**（0V）
- 去抖：10nF 电容与 10K 电阻构成 RC 滤波，时间常数 τ = 10K × 10nF = 0.1ms，消除机械抖动
- 复位键 S2 的上拉链路为 VCC_3.3 → R8(10K) → R9(10K) → NRST，双重限流保护

### 3.3 LED 指示灯电路

开发板有 3 个 LED，由 GPIO 控制点亮/熄灭。

| LED | 颜色 | 功能 | 连接引脚 | 限流电阻 | 点亮逻辑 |
|-----|------|------|---------|---------|---------|
| 电源 LED | 红色 | 上电指示 | VCC_3.3 直连 | R19(1K) | 上电常亮 |
| 下载 LED | 橙色 | ST-Link 状态指示 | STLK LED 控制 | R27(1K) | 下载时闪烁 |
| 用户 LED | 蓝色 | 用户自定义 | PC13 | 1K | GPIO 拉高点亮 |

- 工作电流：约 (3.3V - 2V) / 1K = 1.3mA
- **用户 LED（PC13）** 在代码中通过 `HAL_GPIO_WritePin` 或 `GPIO_TogglePin` 控制

| 4 | GPIO1 | E53_GPIO1 | 通用 IO |
| 5 | ADC | ADC1_IN3 | 模拟输入 |
| 6 | DAC | DAC1_OUT2 | 模拟输出 |
| 7 | GPIO2 | E53_GPIO2 | 通用 IO |
| 8 | GPIO3 | E53_GPIO3 | 通用 IO |
| 9 | IIC_SCL | I2C1_SCL | I2C 时钟 |

| 11 | VCC_5.0 | - | 5V 电源 |
| 12 | GND | - | 地 |
| 13 | VCC_3.3 | - | 3.3V 电源 |
| 14 | GND | - | 地 |
| 15 | SPI_MISO | SPI1_MISO | SPI 主入从出 |
| 16 | SPI_MOSI | SPI1_MOSI | SPI 主出从入 |

### 3.5 通信扩展接口

通信扩展接口由两个 8 针排针（P3 + P4）组成，用于外接 NB-IoT / 2G / WiFi / LoRa 等通信模组。

#### P3（SPI3 + 控制信号）

| 引脚 | 信号 | 说明 |
|------|------|------|
| 1 | WAN_RI | 振铃指示（网络事件通知） |
| 2 | SPI3_NSS | SPI3 片选 |
| 3 | SPI3_MISO | SPI3 主入从出 |
| 4 | SPI3_SCK | SPI3 时钟 |
| 5 | SPI3_MOSI | SPI3 主出从入 |
| 6 | GND | 地 |
| 7 | NC | 未连接 |
| 8 | NC | 未连接 |

#### P4（电源 + UART + 控制）

| 引脚 | 信号 | 说明 |
|------|------|------|
| 1 | V5.0 | 5V 电源（模组供电） |
| 2 | VCC_3.3 | 3.3V 电源 |
| 3 | VCC_3.3 | 3.3V 电源（并联） |
| 4 | NC | 未连接 |
| 5 | WAN_AT_UART_RX | UART 接收（AT 指令） |
| 6 | WAN_AT_UART_TX | UART 发送（AT 指令） |
| 7 | NC | 未连接 |
| 8 | RESET_KEY | 模块复位 |

#### 工作原理

- 通信模组通过 **UART** 接收 AT 指令进行控制（联网、数据收发）
- **SPI3** 用于高速数据传输场景
- **5V + 3.3V 双电源** 满足不同模组供电需求
- **WAN_RI** 信号用于模组主动通知主控（如来电、数据到达）
- **RESET_KEY** 可由主控 GPIO 控制通信模组复位

## 五、电源系统

```
USB 5V ──► DCDC (5V → 3.3V) ──► VCC_3.3 (系统主电源)
                                    │
                                    ├── MCU (STM32L431RCT6)
                                    ├── ST-Link (STM32F103C8T6)
                                    ├── LCD
                                    ├── E53 扩展板 (3.3V)
                                    ├── QSPI Flash
                                    └── 各 GPIO 上拉

V5.0 (直通 USB 5V)
   ├── 通信扩展模组 (5V 供电)
   ├── E53 扩展板 (5V 供电)
   └── 预留接口 (5V 供电)
```

- MCU 供电电压：3.3V，IO 电压：3.3V
- 外围器件均使用 100nF 去耦电容就近滤波
- E53 接口额外使用 47μF 大电容做低频滤波

## 六、开发注意事项

1. **调试串口**：USART2（PA2/PA3）已用于 printf 调试输出，代码中通过 `_write` 函数重定向至 UART，不要将其用于其他用途
2. **用户 LED**（PC13）：部分 STM32L4 系列的 PC13 连接 RTC 相关功能，操作时注意不要干扰 RTC 配置
3. **按键去抖**：硬件已有 10nF 电容去抖，软件中仍建议增加 10-20ms 的延时去抖判断
4. **SPI 总线分频**：SPI1（E53）、SPI2（LCD）、SPI3（通信模组）三条 SPI 总线独立，互不干扰
5. **链接脚本**：默认栈 1KB（0x400）、堆 512B（0x200），使用 LCD 或 FatFs 时可能需要增大
6. **printf 浮点**：编译器已启用 `-u _printf_float`，可直接使用 `printf("%.2f", val)` 输出浮点数
7. **外扩 Flash**（W25Q64）通过 QSPI 连接，注意操作时需先初始化 QSPI 外设
8. **通信模组 AT 指令**：通过 WAN_AT_UART 发送，波特率需与模组匹配（常见 9600 或 115200）
